<RecipeHeader.Description>Report every written argument of explicit Java new expressions with original node IDs, lexical construction and written argument ordinals, source spans, actual expression types and bounded source String evidence. An optional constructor pattern selects attributed matching targets. Zero-argument constructions supply no argument rows.
