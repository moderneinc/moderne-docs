<RecipeHeader.Description>Report explicit return sites owned by ordinary methods with bodies, retaining actual method, body, return and direct expression identities, independently nullable attribution and original printer ranges. Preserve bare returns, explicit null expressions and repeated physical sites without unwrapping expressions. Exclude lambda-owned returns and constructor or initializer bodies; independent nested ordinary methods own their returns.
