<RecipeHeader.Title>Generate `Inbound` and `Outbound` from export ranges</RecipeHeader.Title>

<RecipeHeader.Description>Generate a Sylva `Inbound` or `Outbound` for each `VRFRouteConfiguration.spec.export` range the `classifications` option names as a load balancer pool or an egress NAT pool. Nothing in the legacy group tells the two apart, so an unclassified range is reported and left alone rather than guessed at.</RecipeHeader.Description>

</RecipeHeader>
