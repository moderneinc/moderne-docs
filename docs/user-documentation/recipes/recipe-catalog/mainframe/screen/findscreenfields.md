<RecipeHeader.Title>Find every screen field and the COBOL behind it</RecipeHeader.Title>

<RecipeHeader.Description>Report every field of every CICS map set and IMS format set — where it is drawn, how long it is, how it is protected, what it is drawn with — and the COBOL data item that reaches it, and mark the definitions the report was read from. The two technologies join to the program at opposite ends: BMS generates a symbolic map, so the program names an item per field and the join is a name; MFS generates nothing, so the program is handed an area and lays a copybook of its own over it, and the join is a displacement matched by order and length. Each screen is also written out as the terminal paints it, one row per line with the literals in place and an underscore where a field goes, which is what a green screen viewer draws. Three ways the two halves can disagree are reported as findings: a message longer or shorter than the area a program sends it from, a copybook item no message field lands on, and a field drawn on the screen that no message carries. `AnalyzeScreenFields` answers the same questions and changes nothing.</RecipeHeader.Description>

</RecipeHeader>
