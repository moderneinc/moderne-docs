<RecipeHeader.Title>Find every data set a job step allocates</RecipeHeader.Title>

<RecipeHeader.Description>Report each job step in the order it runs and every DD it allocates, and mark the DD cards the report is drawn from: the data set, whether it is a generation, its disposition, and the record format, record length, block size, space and unit it is allocated with. Read with the procedure library supplied, the steps are the ones the job actually runs — a step that calls a procedure is replaced by the procedure's own steps, each naming the procedure it came from, with the job's DD overrides applied and its symbols filled in, so `DSN=&HLQ..CLMMAST` reads as the data set the catalog holds. What the programs do with each data set is carried across from the batch join. `AnalyzeJclStepDetail` answers the same question and changes nothing.</RecipeHeader.Description>

</RecipeHeader>
