<RecipeHeader.Title>Migrate `WireMockConfigurationCustomizer` beans to `@ConfigureWireMock`</RecipeHeader.Title>

<RecipeHeader.Description>`@AutoConfigureWireMock` applied every `WireMockConfigurationCustomizer` bean in the test context, but Spring Cloud Contract 5.0 removed that interface and `wiremock-spring-boot` only reads its configuration from `@ConfigureWireMock`. Customizer beans that only register extensions with public no-arg constructors are replaced by `extensions = {...}` on the `@ConfigureWireMock` annotations of the same project; other customizer beans are annotated with a `TODO(migrate-wiremock)` comment.</RecipeHeader.Description>

</RecipeHeader>
