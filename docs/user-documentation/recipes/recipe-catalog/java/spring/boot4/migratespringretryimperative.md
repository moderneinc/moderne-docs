<RecipeHeader.Description>Migrate imperative spring-retry usage to Spring Framework 7's `org.springframework.core.retry` support. `RetryTemplate` configuration with an exact Spring Framework 7 equivalent, such as `RetryTemplate.builder()` chains and templates configured with `SimpleRetryPolicy`, `FixedBackOffPolicy` or `ExponentialBackOffPolicy`, becomes `new RetryTemplate(RetryPolicy.builder()...build())`, with spring-retry's defaults made explicit. Everything else, such as callbacks reading the `RetryContext`, `RecoveryCallback`s, `RetryListener`s and policies configured elsewhere, moves to a generated `SpringRetryCompat` class that preserves spring-retry's semantics on top of Spring Framework 7's `RetryTemplate`, so that spring-retry can be removed.</RecipeHeader.Description>

</RecipeHeader>
